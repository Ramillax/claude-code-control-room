# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep discussions about the
work. Harassment, insults and personal attacks are not accepted in issues, pull requests or any
other project space.

The maintainer may edit or remove comments, and block participants, who don't follow this.
To report a problem, contact the maintainer privately through their GitHub profile.
